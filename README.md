# Dental Pro Site

A mobile-first Next.js dental practice website inspired by modern dental marketing sites, without copying another business's branding or content.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Before publishing

Update the practice name, dentist photo, phone, address, hours, booking URL, financing provider, membership pricing, reviews, privacy policy, accessibility statement, and contact-form handling.

The included appointment form is a front-end demo only and does not send/store protected health information.
